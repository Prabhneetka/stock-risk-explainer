Stock Risk Explainer

Stock Risk Explainer is a simple **AI-assisted finance web app** that helps users understand  
**risk vs return** for publicly traded stocks using historical data and clear explanations.

The goal of this project is not stock prediction, but **financial understanding** —  
especially for retail investors and students.

---

## What This App Does

- Takes a stock ticker (e.g., AAPL, MSFT, GOOGL)
- Visualizes historical stock prices
- Calculates basic risk metrics:
  - Average return
  - Volatility
  - Best and worst performing periods
- Explains stock risk in **plain English**, not technical jargon
